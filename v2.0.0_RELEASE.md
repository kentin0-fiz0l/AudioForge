## 🚀 Installation

### Quick Install
```bash
cd AudioForge
./install-all-plugins.sh
```

### Verify Installation
```bash
./verify-installation.sh
```

### DAW Setup
1. **Logic Pro:** Preferences → Plug-in Manager → Reset & Rescan
2. **Ableton Live:** Preferences → Plug-ins → Rescan
3. **Reaper:** Options → Plug-ins → VST → Re-scan
4. **FL Studio:** Options → Manage plugins → Find more plugins

### Installation Paths
- **Plugins:** `~/Library/Audio/Plug-Ins/VST3/`
- **User Presets:** `~/Library/Application Support/AudioForge/{PluginName}/Presets/`
- **Backups:** `~/Library/Audio/Plug-Ins/VST3_Backup_*/`

## 📝 Using Presets

### Saving a Preset
1. Tweak parameters to your liking
2. Click **"Save"** in preset browser
3. Preset auto-named (or enter custom name)
4. Select category (optional)
5. Done! Preset saved to user directory

### Loading a Preset
1. Click preset dropdown menu
2. Browse by category (🏭 Factory / 👤 User)
3. Click to load instantly
4. Parameters update in real-time

### Managing Presets
- **Delete:** Click "Delete" button (user presets only)
- **Export:** Copy `.afpreset` files from user directory
- **Share:** Send `.afpreset` files to others
- **Backup:** User presets auto-backed up with plugin updates

---

## 🎹 Using MIDI Learn

### Assigning a Controller
1. **Right-click** any parameter knob/slider
2. Select **"Learn MIDI CC"**
3. **Move** your MIDI controller
4. Parameter now responds to that CC!

### Removing Assignments
1. **Right-click** mapped parameter
2. Select **"Clear MIDI Mapping"**

### Tips
- ✅ Mappings saved with projects automatically
- ✅ Multiple parameters can use same CC
- ✅ Works with any MIDI CC (0-127)
- ✅ Zero latency, real-time response

## 🛠️ Technical Details

### File Format
- **Preset Files:** `.afpreset` (JSON-based, human-readable)
- **Size:** 2-5 KB per preset
- **Structure:** Plugin name, version, category, author, all parameter values

### State Persistence
- **MIDI Learn mappings:** Saved with project
- **Preset manager state:** Saved with project
- **Last loaded preset:** Remembered across sessions

### System Requirements
- **macOS:** 10.13+ (High Sierra)
- **Architecture:** Universal Binary (Intel + Apple Silicon)
- **DAW:** Any VST3-compatible host
- **Disk Space:** ~200 MB for 18 plugins

## 🐛 Known Issues

### macOS Gatekeeper
**Issue:** "Plugin is damaged" warning on first load  
**Fix:** 
```bash
xattr -cr ~/Library/Audio/Plug-Ins/VST3/*.vst3
```

### DAW Not Finding Plugins
**Issue:** Plugins don't appear after installation  
**Fix:**
1. Verify installation: `./verify-installation.sh`
2. Check DAW VST3 path in preferences
3. Force plugin rescan in DAW

### Empty Preset Browser
**Issue:** No presets showing  
**Fix:** Plugin will auto-scan on next load. Click dropdown to refresh.
