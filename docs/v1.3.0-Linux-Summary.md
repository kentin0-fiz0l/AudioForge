## 🐧 Build on Linux (4-6 hours first time)

### Prerequisites

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install -y build-essential cmake git dpkg-dev rpm fakeroot wget curl
```

**Fedora:**
```bash
sudo dnf install -y gcc-c++ cmake git rpm-build dpkg wget curl
```

### Quick Build Process

```bash
# 1. Clone repository (5 min)
git clone --recursive https://github.com/kentin0-fiz0l/AudioForge.git
cd AudioForge

# 2. Build all 13 plugins (30-45 min)
./build-installer.sh

# 3. Build Linux packages (2-5 min)
cd installers/linux
chmod +x build-packages.sh
./build-packages.sh
```

**Outputs:**
- `audioforge-1.3.0-amd64.deb` (~45 MB) - Debian/Ubuntu
- `audioforge-1.3.0-1.fc39.x86_64.rpm` (~46 MB) - Fedora/RHEL
- `AudioForge-1.3.0-x86_64.AppImage` (~47 MB) - Universal

## 📦 Package Formats

### .deb (Debian/Ubuntu)

**Install:**
```bash
sudo dpkg -i audioforge-1.3.0-amd64.deb
```

**Installs 13 plugins to:**
- `/usr/lib/vst3/*.vst3`

**Uninstall:**
```bash
sudo apt remove audioforge
```

### .rpm (Fedora/RHEL)

**Install:**
```bash
sudo rpm -i audioforge-1.3.0-1.fc39.x86_64.rpm
# or
sudo dnf install audioforge-1.3.0-1.fc39.x86_64.rpm
```

**Installs 13 plugins to:**
- `/usr/lib64/vst3/*.vst3`

**Uninstall:**
```bash
sudo dnf remove audioforge
```

### AppImage (Universal)

**Run:**
```bash
chmod +x AudioForge-1.3.0-x86_64.AppImage
./AudioForge-1.3.0-x86_64.AppImage
```

**Installs 13 plugins to:**
- `~/.vst3/*.vst3` (user directory, no sudo required)

**No uninstaller needed** - just delete the plugins from `~/.vst3/`

## 💡 Tips for Linux Build

**Performance:**
- Use a dedicated build VM (Ubuntu 22.04 LTS recommended)
- 4+ CPU cores recommended (parallel plugin builds)
- 8GB+ RAM for comfortable building
- SSD storage for faster compilation

**Testing:**
- Keep separate VMs for testing (don't build and test on same VM)
- Test .deb on Ubuntu 22.04 AND 24.04
- Test .rpm on Fedora 39 AND 40
- Test AppImage on at least one non-Debian/Fedora distro (e.g., Arch)

**Cost-Effective:**
- No certificates needed (completely free!)
- Can build in Docker containers for reproducibility
- GitHub Actions could automate Linux builds (future consideration)
