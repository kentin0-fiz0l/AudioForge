# WaveShaper User Manual

**AudioForge WaveShaper v1.0.0**

Waveshaping distortion with multiple curve types

---

## Overview

**WaveShaper** provides harmonic distortion through waveshaping with:

- **4 Curve Types**: Soft, Hard, Asymmetric, Fold
- **Drive**: 0-100% (input gain before shaping)
- **Mix**: Blend distorted signal with clean
- **Output Gain**: Compensate for level changes

---

## Quick Start

### Subtle Warmth

1. **Curve**: Soft
2. **Drive**: 20-30%
3. **Mix**: 50%
4. Result: Gentle saturation

### Heavy Distortion

1. **Curve**: Hard or Fold
2. **Drive**: 70-90%
3. **Mix**: 80-100%
4. Result: Aggressive distortion

---

## Parameters

### Curve Type

**Soft**: Smooth, tube-like saturation (odd harmonics)
**Hard**: Aggressive clipping (even + odd harmonics)
**Asymmetric**: Lopsided distortion (rich harmonics)
**Fold**: Wave-folding synthesis (metallic, harsh)

---

### Drive

**Range**: 0-100%
**Description**: Input gain before waveshaping

- **0-30%**: Subtle warmth
- **40-60%**: Moderate distortion
- **70-100%**: Heavy distortion

---

### Mix

**Range**: 0-100%
**Description**: Wet/dry blend

- **100%**: Full distortion
- **50%**: Parallel processing
- **0%**: Bypass

---

## Use Cases

### 1. Bass Saturation

**Settings**: Soft curve, Drive 40%, Mix 70%
**Result**: Harmonically rich bass

### 2. Drum Crunch

**Settings**: Hard curve, Drive 60%, Mix 80%
**Result**: Aggressive drum punch

### 3. Creative Synthesis

**Settings**: Fold curve, Drive 80%, Mix 100%
**Result**: Metallic, synthetic textures

---

## Tips

- Start with low Drive, increase gradually
- Use Mix for parallel distortion (blend clean + distorted)
- Try automating Curve type for dynamic changes
