# AudioForge v1.3.0 - Production Distribution Release

**13 professional audio plugins** with complete cross-platform support and zero security warnings.

🌐 **[Visit the AudioForge Website](https://audioforge-site.sfo3.cdn.digitaloceanspaces.com/index.html)** - Plugin showcase, documentation, and roadmap

## 🎉 What's New

### Advanced Suite (New)
- **GranularEngine** - Real-time granular synthesis with MIDI integration and visualization
- **SpectralFreeze** - Professional spectral manipulation with 5 effects and spectrogram display

### Core Suite (11 Plugins)
SimpleGain • PanUtil • BasicSynth • CleanDelay • SimpleEQ • SimpleComp • WaveShaper • Saturation • ChorusFlanger • Reverb • FreezeFX

## 📦 Downloads

### macOS ✅ Ready Now
**[AudioForge-v1.3.0-macOS.dmg](AudioForge-v1.3.0-macOS.dmg)** (80 MB)
- Formats: VST3 + AU (26 plugins total)
- macOS 10.13+ (Intel & Apple Silicon)
- **Signed & Notarized** - Zero Gatekeeper warnings
- Double-click DMG → Run `Install AudioForge.command`

### Windows 🔧 Coming Soon
**AudioForge-Setup-v1.3.0.exe** (~80 MB)
- Format: VST3 (13 plugins)
- Windows 10/11 64-bit
- One-click installer to `C:\Program Files\Common Files\VST3\`

### Linux 🐧 Coming Soon
**Three package formats**:
- `audioforge-1.3.0-amd64.deb` (Debian/Ubuntu)
- `audioforge-1.3.0-1.fc39.x86_64.rpm` (Fedora/RHEL)
- `AudioForge-1.3.0-x86_64.AppImage` (Universal)

**No code signing required - zero warnings!**

## 🔧 System Requirements

**macOS**: 10.13+, 200MB disk, VST3/AU-compatible DAW
**Windows**: 10/11 64-bit, 200MB disk, VST3-compatible DAW
**Linux**: Ubuntu 22.04+/Fedora 39+, 200MB disk, VST3-compatible DAW

## 📝 Key Changes

### Infrastructure
- macOS code signing with Developer ID Application
- Apple notarization with secure timestamps
- Windows NSIS installer with uninstall support
- Linux packages (.deb, .rpm, AppImage)
- 1,900+ lines of documentation

### Plugins
- Updated to v1.3.0
- Enhanced timestamp signatures for notarization
- Improved DAW compatibility
- Bug fixes and performance improvements

## 🐛 Known Issues

- Windows builds may show SmartScreen warnings (unsigned)
- Linux packages are x86_64 only (ARM coming soon)
- AAX format not yet supported (planned for v1.4.0)
