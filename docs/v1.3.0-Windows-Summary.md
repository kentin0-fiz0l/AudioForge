## 🖥️ Build on Windows (6-8 hours first time)

### Prerequisites

**1. Visual Studio 2022** (Community Edition - Free)
- Workload: "Desktop development with C++"
- Download: https://visualstudio.microsoft.com/downloads/

**2. NSIS 3.x** (Free)
- Download: https://nsis.sourceforge.io/Download

**3. Git for Windows** (Free)
- Download: https://git-scm.com/download/win

### Quick Build Process

```cmd
REM 1. Clone repository (5 min)
cd C:\Projects
git clone --recursive https://github.com/kentin0-fiz0l/AudioForge.git
cd AudioForge

REM 2. Build all 13 plugins (30-45 min)
installers\windows\build-all-plugins.bat

REM 3. Stage plugins (2 min)
installers\windows\stage-plugins.bat

REM 4. Create installer (1 min)
cd installers\windows
makensis audioforge.nsi

REM 5. Test installer
AudioForge-Setup-v1.3.0.exe
```

**Output:**
- `installers\windows\AudioForge-Setup-v1.3.0.exe` (60-80 MB)
- Installs 13 VST3 plugins to standard location

## 🔐 Code Signing (Optional but Recommended)

### Option 1: EV Certificate ($400/year) - **Best User Experience**

**Pros:**
- ✅ Zero SmartScreen warnings on first install
- ✅ Instant trust from Windows
- ✅ Professional appearance

**Vendors:**
- DigiCert: https://www.digicert.com/signing/code-signing-certificates
- GlobalSign: https://www.globalsign.com/en/code-signing-certificate

### Option 2: Standard OV Certificate ($200/year) - **Budget Option**

**Pros:**
- ✅ Eventually builds reputation (2-4 weeks)
- ✅ More affordable
- ✅ Still shows publisher name

**Cons:**
- ⚠️ Initial SmartScreen warnings
- ⏳ Requires time to build trust

**Vendors:**
- Sectigo: https://sectigo.com/ssl-certificates-tls/code-signing
- SSL.com: https://www.ssl.com/code-signing/

### Option 3: No Certificate (Free) - **Development/Testing Only**

**Pros:**
- ✅ Free
- ✅ OK for personal testing

**Cons:**
- ❌ Persistent SmartScreen warnings
- ❌ Users must click "More info" → "Run anyway"
- ❌ Poor user experience

### Signing Process

```powershell
cd installers\windows
.\sign.ps1 -CertificatePath "C:\path\to\certificate.pfx" -CertificatePassword "your-password"
```

**What gets signed:**
- All 13 VST3 plugin binaries
- AudioForge-Setup-v1.3.0.exe installer

## 💡 Tips

**For Best Results:**
- Use EV certificate for zero SmartScreen warnings
- Test on multiple Windows versions (10 & 11)
- Test in at least 2 DAWs (Reaper + FL Studio/Ableton)
- Keep build environment VM separate from testing VM

**Time-Saving:**
- Keep Visual Studio 2022 VM snapshot for faster rebuilds
- Use automated build scripts (don't build plugins manually)
- Stage plugins directly from build output

**Cost-Effective:**
- Start with unsigned for testing (free)
- Upgrade to Standard OV when ready ($200/year)
- Consider EV for professional releases ($400/year)
