# AudioForge v1.1.1 - Multi-Platform Release 🎉

**Multi-platform support is here!** AudioForge now available for Windows and Linux.

This release adds Windows and Linux installers, making AudioForge accessible to all major desktop platforms.

---

## 📦 What's New in v1.1.1

### Platform Support:
- ✅ **Windows 10/11** - Native Windows installer (.exe)
- ✅ **Linux** - Multiple package formats (.deb, .rpm, AppImage)
- ✅ **macOS** - Updated installer with bug fixes

### New Features:
- Windows NSIS installer with Start Menu integration
- Linux system-wide installation support
- Automated uninstaller for all platforms
- Universal Linux AppImage (works on all distros)

---

## 💾 Downloads

### Windows (NEW!)
**[AudioForge-Setup-v1.1.1.exe](https://github.com/kentin0-fiz0l/AudioForge/releases/download/v1.1.1/AudioForge-Setup-v1.1.1.exe)** (~50 MB)

**Installation:**
1. Download the `.exe` installer
2. Double-click to run
3. **Windows SmartScreen warning** - Click "More info" → "Run anyway" (unsigned installer)
4. Follow installation wizard
5. Plugins install to: `C:\Program Files\Common Files\VST3\`
6. Rescan plugins in your DAW

**Tested on:** Windows 10 (21H2, 22H2), Windows 11
**DAWs tested:** Reaper, FL Studio 21, Ableton Live 11/12, Bitwig Studio 5

---

### Linux (NEW!)
Choose the package format for your distribution:

**Ubuntu/Debian (.deb):**
```bash
wget https://github.com/kentin0-fiz0l/AudioForge/releases/download/v1.1.1/audioforge-1.1.1.deb
sudo dpkg -i audioforge-1.1.1.deb
```

**Fedora/RHEL (.rpm):**
```bash
wget https://github.com/kentin0-fiz0l/AudioForge/releases/download/v1.1.1/audioforge-1.1.1.rpm
sudo rpm -ivh audioforge-1.1.1.rpm
```

**Universal AppImage (all distros):**
```bash
wget https://github.com/kentin0-fiz0l/AudioForge/releases/download/v1.1.1/AudioForge-1.1.1-x86_64.AppImage
chmod +x AudioForge-1.1.1-x86_64.AppImage
./AudioForge-1.1.1-x86_64.AppImage --install
```

**Plugins install to:** `/usr/lib/vst3/` (system-wide) or `~/.vst3/` (user)
**Tested on:** Ubuntu 22.04/24.04, Fedora 39/40, Arch Linux
**DAWs tested:** Reaper, Bitwig Studio 5, Ardour 8

### macOS (Updated)
**[AudioForge-v1.1.1-macOS.dmg](https://github.com/kentin0-fiz0l/AudioForge/releases/download/v1.1.1/AudioForge-v1.1.1-macOS.dmg)** (~70 MB)

**Installation** (same as v1.1.0):
1. Download DMG
2. **Right-click** DMG → Select **"Open"** (don't double-click!)
3. Click **"Open"** in security dialog
4. Run **"Install AudioForge.command"**
5. Enter password when prompted
6. Rescan plugins in your DAW

**Compatibility:** macOS 10.13+ (Intel & Apple Silicon)

## 🐛 Known Issues

### Windows:
- **SmartScreen warning**: Expected for unsigned installers (See installation instructions above)
- **First scan slow**: Initial plugin scan may take 30-60 seconds (normal for JUCE)

### Linux:
- **JACK/PipeWire**: May need manual audio server configuration
- **Some distros**: May require `libvst3sdk` package (install via package manager)

### macOS:
- **Unsigned warning**: Same as v1.1.0 (right-click → Open to bypass)

See [GitHub Issues](https://github.com/kentin0-fiz0l/AudioForge/issues) for full list.
