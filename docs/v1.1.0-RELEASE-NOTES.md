# AudioForge v1.1.0 - First Production Release 🎉

**10 professional audio plugins, free and open source!**

This is the first production release of AudioForge with a complete macOS installer. Windows and Linux installers coming in v1.1.1 (next 2 weeks).

---

## 📦 What's Included

### 10 Professional Plugins:
- **SimpleGain** - Clean gain/volume control
- **PanUtil** - Stereo panning and width control
- **BasicSynth** - Subtractive synthesizer (3 oscillators, filters, envelopes)
- **CleanDelay** - Stereo delay with feedback and filtering
- **SimpleEQ** - 3-band parametric equalizer
- **SimpleComp** - Compressor with auto-makeup gain
- **WaveShaper** - Distortion and saturation
- **Saturation** - Analog-style harmonic saturation
- **ChorusFlanger** - Modulation effects
- **Reverb** - Algorithmic reverb

**Formats**: VST3 + AU (Audio Units)
**Compatibility**: macOS 10.13+ (Intel & Apple Silicon)

## 💾 Downloads

### macOS (Universal Binary)
**[AudioForge-v1.1.0-macOS.dmg](https://github.com/kentin0-fiz0l/AudioForge/releases/download/v1.1.0/AudioForge-v1.1.0-macOS.dmg)** (70 MB)

**Installation Instructions** (IMPORTANT - Read First!):

⚠️ **This release is unsigned** - macOS will show a security warning. This is normal for free, open-source software.

**To install:**
1. Download `AudioForge-v1.1.0-macOS.dmg`
2. **Right-click** the DMG file → Select **"Open"** (don't double-click!)
3. Click **"Open"** in the security dialog
4. Double-click **"Install AudioForge.command"**
5. Enter your password when prompted
6. **Rescan plugins** in your DAW

**To uninstall:**
- Run "Uninstall AudioForge.command" from the DMG

## 🚀 Getting Started

1. **Download** the macOS DMG (see above)
2. **Install** following the instructions
3. **Open your DAW** (Logic Pro, Ableton Live, Reaper, etc.)
4. **Rescan plugins** (each DAW is different - check your DAW's preferences)
5. **Load a plugin** - they appear under "Manufacturer: AudioForge"
6. **Read the manual** - check [docs/manuals/](https://github.com/kentin0-fiz0l/AudioForge/tree/main/docs/manuals)

**Tested in:**
- Logic Pro X / Logic Pro 11
- Ableton Live 11/12
- Reaper 6/7
- FL Studio 21
- Bitwig Studio 5
