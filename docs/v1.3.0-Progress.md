## 🔧 Next: Notarization (15-30 min wait)

### Step 1: Setup Notarization Credentials (One-Time)

**Create App-Specific Password:**
1. Go to https://appleid.apple.com
2. Sign In → Security → App-Specific Passwords
3. Click '+' → Name: "AudioForge Notarization"
4. Copy the generated password (save it!)

**Get Team ID:**
1. Go to https://developer.apple.com/account
2. Navigate to Membership section
3. Copy your Team ID

**Run Setup Script:**
```bash
cd ~/Projects/Active/AudioForge
./installers/setup-notarization.sh
```

**You'll need:**
- Apple ID: jkino.ji@gmail.com
- Team ID: (from developer.apple.com/account)
- App-specific password: (created above)

### Step 2: Notarize the DMG

```bash
./installers/notarize-dmg.sh releases/installers/AudioForge-v1.3.0-macOS.dmg
```

**What happens:**
1. Uploads DMG to Apple notarization service
2. Waits for Apple approval (typically 5-30 minutes)
3. Downloads notarization ticket
4. Staples ticket to DMG
5. Verifies notarization

**Expected output:**
```
✓ DMG submitted for notarization
→ Waiting for Apple approval... (this may take 5-30 minutes)
✓ Notarization approved
✓ Ticket stapled to DMG
✓ Verification: source=Notarized Developer ID
```

### Step 3: Test on Clean macOS

**Test Installation:**
1. Copy DMG to test Mac (or use current Mac)
2. Double-click DMG
3. **Expected:** Zero Gatekeeper warnings ✓
4. Run "Install AudioForge.command"
5. Open DAW and scan plugins
6. **Expected:** All 13 plugins load without errors

**Verification Commands:**
```bash
# Verify DMG is notarized

# Expected: "source=Notarized Developer ID"
```
