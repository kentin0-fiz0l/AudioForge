**Release Date**: August 31, 2026
**Status**: Production Ready (macOS)

## 🎉 What's New in v1.3.0

AudioForge v1.3.0 marks the **first official production release** with professional code signing and notarization for macOS. This release includes **13 professional audio plugins** (11 core + 2 advanced) fully signed and notarized with **zero security warnings** on macOS.

**Release Strategy**: We're shipping v1.3.0 with macOS first to get the plugins into users' hands immediately. Windows and Linux installers will follow in v1.3.1 and v1.3.2 over the coming weeks.

### New Plugins (Advanced Suite)

**GranularEngine** - Real-time Granular Synthesis
- 6 window functions (Hann, Hamming, Blackman, Tukey, Gaussian, Triangle)
- Grain size, density, and pitch control
- MIDI integration for note triggering
- 10 factory presets
- 60 FPS real-time visualization

**SpectralFreeze** - Professional Spectral Manipulation
- 2048-sample FFT engine
- Freeze/unfreeze with 5 advanced effects:
  - Spectral blur (frequency smearing)
  - Spectral shift (pitch transposition)
  - Spectral gate (frequency filtering)
  - Spectral morph (blend between snapshots)
  - Randomize (controlled chaos)
- 60 FPS spectrogram visualization
- 6 factory presets
- 300+ line user manual

### Core Suite (11 Plugins)

1. **SimpleGain** - Clean gain/volume control with metering
2. **PanUtil** - Stereo panning and width control
3. **BasicSynth** - Subtractive synthesizer
4. **CleanDelay** - Tempo-synced stereo delay
5. **SimpleEQ** - 3-band parametric equalizer
6. **SimpleComp** - Compressor with auto makeup gain
7. **WaveShaper** - Waveshaping distortion
8. **Saturation** - Multi-mode analog saturation
9. **ChorusFlanger** - LFO-based modulation effects
10. **Reverb** - Freeverb-inspired algorithmic reverb
11. **FreezeFX** - Spectral freezing plugin

## 🐛 Known Issues

### macOS
- **First Launch Delay**: DAWs may take longer to scan plugins on first launch (normal behavior)
- **Rosetta 2**: Intel plugins run via Rosetta 2 on Apple Silicon Macs (no issues reported)

### Windows & Linux (Coming Soon)
- **Windows SmartScreen**: Unsigned builds will show warnings (certificate purchase optional)
- **Linux ARM**: x86_64 only (ARM builds planned for future release)
- **AAX Format**: Pro Tools support not yet available (planned for v1.4.0)
