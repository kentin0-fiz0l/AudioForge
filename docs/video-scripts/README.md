## Production Guidelines

### Recording Equipment

**Minimum Requirements**:
- Screen recording software (OBS Studio, ScreenFlow, Camtasia)
- USB microphone or audio interface with condenser mic
- Headphones for monitoring
- DAW with AudioForge plugins installed

**Recommended Specs**:
- **Screen Resolution**: 1920x1080 (1080p)
- **Frame Rate**: 30fps
- **Audio**: 48kHz, 16-bit minimum (24-bit preferred)
- **Screen Recording Bitrate**: 8-15 Mbps for high quality

### Filming Setup

**Before Recording**:
- [ ] Test audio levels (aim for -12 dB peaks on voiceover)
- [ ] Close unnecessary applications
- [ ] Hide desktop clutter
- [ ] Disable notifications (macOS/Windows Do Not Disturb)
- [ ] Use consistent DAW color theme
- [ ] Prepare all audio files and MIDI clips

**During Recording**:
- [ ] Speak clearly at moderate pace
- [ ] Pause 2-3 seconds between sections (easy editing)
- [ ] Keep cursor movements slow and deliberate
- [ ] Demonstrate visually (don't just narrate)
- [ ] Record in segments (easier to fix mistakes)

**After Recording**:
- [ ] Trim dead air and long waits
- [ ] Speed up progress bars (2x-4x)
- [ ] Add subtle background music (low volume)
- [ ] Color grade to match brand
- [ ] Add lower thirds and on-screen text

### Post-Production Checklist

**Editing** (per video):
- [ ] Cut together segments
- [ ] Add intro animation (AudioForge logo)
- [ ] Add lower thirds for section titles
- [ ] Add on-screen text for key points
- [ ] Speed up slow sections (waiting, progress bars)
- [ ] Add background music (royalty-free, low volume ~-30 dB)
- [ ] Add sound effects for clicks/actions
- [ ] Color grade video
- [ ] Export final video (H.264, 1080p, 8 Mbps)

**YouTube Upload**:
- [ ] Upload video
- [ ] Add title, description (from script)
- [ ] Add timestamps/chapters
- [ ] Create custom thumbnail
- [ ] Add to AudioForge Tutorials playlist

- [ ] Add cards at 1/3 and 2/3 points
- [ ] Set tags (from description)

### YouTube Optimization

**Thumbnail Design**:
- Plugin UI screenshot + text overlay
- High contrast, readable at small sizes
- Consistent style across series
