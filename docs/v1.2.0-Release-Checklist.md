# AudioForge v1.2.0 - Advanced Effects Suite 🎉

We're excited to announce AudioForge v1.2.0, featuring two powerful new plugins for creative sound design!

## 🆕 What's New

### GranularEngine - Real-Time Granular Synthesis
Transform any audio into lush textures and evolving soundscapes with professional granular processing.

**Features:**
- **6 Window Functions**: Hann, Gaussian, Triangle, Tukey, Blackman, Kaiser for different grain characters
- **Flexible Grain Control**: Size (10-500ms), density (1-50 grains/sec), pitch (-24 to +24 semitones)
- **Advanced Playback**: Forward, backward, and pingpong grain direction modes
- **MIDI Integration**: Velocity modulation for expressive grain density control
- **10 Factory Presets**: Quick-start templates for common granular techniques
- **Real-Time Visualization**: 60 FPS waveform, window preview, and grain activity display

**Perfect for**: Ambient pads, rhythmic textures, drone layers, experimental sound design

---

### SpectralFreeze - Professional Spectral Manipulation
Capture and manipulate the frequency content of audio with surgical precision.

**Core Features:**
- **2048-Sample FFT Engine**: High-quality spectral processing with 75% overlap
- **Spectral Freeze**: Capture and hold any spectrum indefinitely
- **Frequency Filtering**: Surgical low-cut and high-cut filters
- **Spectral Blur**: Gaussian smoothing for ethereal textures

**Advanced Effects:**
- **Stretch**: Time-stretch frozen spectrum (1x to 5x slower)
- **Shift**: Frequency shifting (±2 octaves) for formant manipulation
- **Morph**: Blend between live and frozen spectrum
- **Gate**: Threshold-based bin gating for isolation
- **Randomize**: Phase randomization for granular textures

**Production Features:**
- **60 FPS Spectrogram**: Real-time frequency visualization with frozen overlay
- **6 Factory Presets**: Frozen Blur, Spectral Stretch, Frequency Shifter, and more
- **Parameter Smoothing**: Click-free parameter changes for live performance
- **Tooltips**: Helpful descriptions on every control
- **Full Documentation**: [300+ line user manual](docs/SpectralFreeze-Manual.md) with creative techniques

**Perfect for**: Frozen pads, spectral effects, formant shifting, frequency isolation, creative sound design

## 💿 Installation

### macOS (Developer Preview - Unsigned)

**⚠️ Note**: Plugins are currently unsigned. You may see Gatekeeper warnings.

**To install:**
1. Download `AudioForge-v1.2.0-macOS.zip` below
2. Extract the archive
3. Right-click each plugin → "Open" to bypass Gatekeeper
4. Copy to:
   - VST3: `~/Library/Audio/Plug-Ins/VST3/`
   - AU: `~/Library/Audio/Plug-Ins/Components/`

**Included plugins (VST3 + AU):**
- All 11 Core Suite plugins
- GranularEngine.vst3 / GranularEngine.component
- SpectralFreeze.vst3 / SpectralFreeze.component

**Signed installers coming in v1.3.0!**

---

### Windows / Linux

**Status**: Build from source (professional installers coming in v1.3.0)

```bash
# Clone repository
git clone --recursive https://github.com/kentin0-fiz0l/AudioForge.git
cd AudioForge

# Build a plugin
cd plugins/SpectralFreeze
cmake -B build
cmake --build build

# Plugins auto-install to:
# Windows: C:\Program Files\Common Files\VST3\
# Linux: ~/.vst3/
```
